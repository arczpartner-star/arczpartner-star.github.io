# arcz.kr — ARCZ(아크즈마케팅) 홈페이지

브랜드 가이드라인 VER 1.0(2026.10) 기준 정적 사이트입니다. GitHub Pages(`arczpartner-star.github.io`)에서 그대로 동작합니다.

## 이번 업데이트 (2026.10.26)

- **화면이 깨져 보이던 문제 수정** — 브라우저가 옛 홈페이지의 `style.css`·`app.js`를 기억(캐시)하고 새 HTML과 섞어 쓴 것이 원인이었습니다. 이제 CSS·JS 주소 뒤에 버전(`?v=…`)이 붙어, 파일이 바뀔 때마다 브라우저가 새 파일을 받습니다. 스크립트가 막혀도 내용이 사라지지 않게 안전장치도 넣었습니다.
- **새 페이지 9개** — 소개 · 업종별 솔루션(목록 + 홈서비스·음식점·카페·동네 전문 매장) · 자료실 · 3분 셀프 점검 · 청소업체 사례 이야기 · 개인정보처리방침
- 메뉴: 소개 · ARCZ Method · 서비스 · 업종별 솔루션 · 성과 사례 · 자료실 · 비용 안내 (칼럼·셀프 점검·개인정보처리방침은 하단 메뉴)
- `config.js`는 지금 저장소에 올라가 있는 웹 앱 주소를 그대로 넣어 두었습니다.

## 올리는 법

1. 저장소에 이 폴더의 파일을 **전부 덮어쓰기**로 올립니다(새 파일 추가 + 기존 파일 교체). 지울 파일은 없습니다.
2. 1~3분 뒤 arcz.kr에서 확인합니다. 그래도 옛 화면이 보이면 **Ctrl+F5**(맥은 Cmd+Shift+R)로 한 번 새로 고침하세요. 이번 업데이트부터는 방문자가 따로 새로 고칠 필요가 없습니다.
3. 네이버 서치어드바이저·구글 서치콘솔에 `https://arcz.kr/sitemap.xml`을 다시 제출하면 새 페이지가 빨리 잡힙니다.

## 상담·자료 신청이 시트에 들어오는 모습

세 가지 신청이 모두 같은 `상담신청` 시트로 들어오고, **‘남긴 내용’ 칸 첫 줄**로 구분됩니다. Apps Script는 고칠 필요가 없습니다.

| 신청 | ‘남긴 내용’ 첫 줄 예시 | ‘신청 페이지’ |
|---|---|---|
| 진단 신청 | (손님이 쓴 고민) | `/contact.html`, `/index.html`, `/solution-home.html` … |
| 자료 받기 | `[자료 요청] 린 캔버스 광고 기획법, AI 메뉴 포스터 프롬프트` | `/resources.html` |
| 셀프 점검 후 신청 | `[셀프 점검] 총점 14/24 · A 5/6 · R 1/6 · C 5/6 · Z 3/6 · 먼저 볼 단계: R` | `/checkup.html` |

자료 PDF는 연락처를 남기면 화면에 내려받기 링크가 나오는 방식입니다. 파일 주소를 아는 사람은 바로 받을 수 있는 ‘가벼운 잠금’이라는 점만 알아 두세요.

## 꼭 확인할 것

- **개인정보처리방침** — 실제 운영과 맞는지 확인하세요. 특히 6항 “계정에 2단계 인증 적용”은 아크즈 구글 계정에 2단계 인증을 켜 두셔야 사실이 됩니다. 법률 자문이 아니므로 최종 문구는 개인정보보호위원회 안내나 전문가 확인을 권합니다.
- **청소업체 사례(case-cleaning.html, data.js 첫 사례)** — 업체명과 광고비 총액은 넣지 않았고, 문의 1건당 광고비는 ‘1만 원대 안팎’처럼 범위로만 적어 문의 수와 곱해도 광고비가 계산되지 않게 했습니다. 블로그에 이미 공개한 숫자이지만, 홈페이지 사례 게재도 고객사에 한 번 알려 동의를 받아 두세요.
- **나머지 사례 4개(data.js `CASES`)** — 기존 홈페이지에서 옮긴 수치로, 기간·조건·고객 동의(`note`)가 비어 있습니다. 실제 데이터가 아니거나 동의가 없으면 삭제하세요.
- **‘월 5개사’ 문구**(처음으로 페이지 진단 신청 칸) — 실제 운영과 다르면 고치세요.
- 서체는 Pretendard(jsDelivr)·Montserrat(Google Fonts)를 불러옵니다. 둘 다 SIL OFL 1.1.

## 내 PC에서 미리 보기

폴더를 압축 해제한 뒤 `index.html`을 더블클릭하면 됩니다. 모든 경로가 상대 경로라 이미지·메뉴 이동·셀프 점검이 동작합니다. 신청 폼은 내 PC에서도 실제 시트로 전송되니, 시험할 때는 시트에서 테스트 줄을 지워 주세요.

## 사례·글 추가

`data.js`를 열어 배열 맨 앞에 같은 형식으로 한 덩어리를 추가하면 처음으로·성과 사례·자료실·칼럼 페이지에 자동으로 나옵니다.
