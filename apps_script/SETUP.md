# 상담 신청 → 구글 스프레드시트 연결 (처음 한 번, 약 10분)

arcz.kr의 진단 신청 폼(처음으로·진단 신청 페이지)에 들어온 내용이 **아크즈 구글 계정의 스프레드시트**에 한 줄씩 쌓이고, 동시에 알림 메일이 옵니다.

```
홈페이지 폼 ──(전송)──▶ Apps Script 웹 앱(Code.gs) ──▶ 스프레드시트 '상담신청' 시트
                                              └──▶ 알림 메일(arcz_partner@naver.com)
```

---

## 1. 스프레드시트 만들기

1. **아크즈 구글 계정**으로 로그인한 상태에서 sheets.new 접속 → 새 스프레드시트가 열립니다.
2. 파일 이름을 `ARCZ 상담 신청`으로 바꿉니다. (시트 탭 이름은 스크립트가 자동으로 `상담신청`으로 만듭니다.)

## 2. 스크립트 붙여넣기

1. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. 왼쪽 `Code.gs`의 기존 내용을 모두 지우고, 이 폴더의 **`Code.gs` 내용 전체**를 붙여넣습니다.
3. 맨 위 `CONFIG`에서 필요한 것만 고칩니다.
   - `NOTIFY_EMAILS` — 새 신청 알림을 받을 메일. 여러 개면 `['a@naver.com', 'b@gmail.com']`. 알림이 필요 없으면 `[]`.
   - `RETENTION_MONTHS` — 상담 완료 후 보관 개월 수. **홈페이지 동의 문구(6개월)와 같아야 합니다.**
4. 💾 저장(Ctrl+S). 프로젝트 이름은 `ARCZ 상담 연동`으로 바꿔 두면 찾기 쉽습니다.

## 3. setup 실행 (시트 서식·자동 파기 예약)

1. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **▶ 실행**.
2. 권한 요청 창이 뜹니다 → **권한 검토 → 아크즈 계정 선택**.
3. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → ARCZ 상담 연동(으)로 이동(안전하지 않음) → 허용**.
   본인이 만든 스크립트를 본인 계정에서 쓰는 경우라 정상입니다. 요청 권한은 *이 스프레드시트 편집 · 메일 보내기 · 예약 실행* 세 가지입니다.
4. 스프레드시트로 돌아가면 `상담신청` 시트에 보라색 머리글 13칸이 생겨 있습니다.

## 4. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**.
2. ⚙ 유형 선택 → **웹 앱**.
3. 설명: `arcz.kr 상담 v1`
   - **실행 사용자(Execute as): 나(아크즈 계정)**
   - **액세스 권한이 있는 사용자(Who has access): 모든 사용자(Anyone)**
     → 홈페이지 방문자는 구글 로그인 없이 신청하므로 반드시 '모든 사용자'여야 합니다. 시트 자체는 공개되지 않습니다.
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 복사합니다.
5. 브라우저 새 탭에 그 URL을 붙여넣어 열어 보세요. `{"ok":true,"service":"arcz-lead",…}`가 보이면 정상입니다.

> 구글 워크스페이스(회사 도메인) 계정이라 '모든 사용자'가 안 보이면, 관리자 설정에서 외부 공유가 막힌 경우입니다. 개인 Gmail 계정으로 만들거나 관리자에게 허용을 요청하세요.

## 5. 홈페이지에 주소 넣기

1. 홈페이지 폴더의 **`config.js`**를 메모장 등으로 엽니다.
2. `leadEndpoint: ''`의 따옴표 안에 복사한 URL을 붙여넣습니다.
   ```js
   window.ARCZ_CONFIG = {
     leadEndpoint: 'https://script.google.com/macros/s/AKfy……/exec'
   };
   ```
3. GitHub 저장소에 `config.js`만 다시 올립니다(다른 파일은 그대로).
4. 1~3분 뒤 arcz.kr/contact 에서 테스트 신청 → 시트에 한 줄 + 알림 메일이 오면 끝입니다. 테스트 줄은 지워 주세요.

주소를 넣기 전에는 폼 아래에 "상담 접수 주소가 아직 연결되지 않았습니다" + 전화·카카오톡 안내가 나옵니다(접수가 사라지지 않도록).

## 매일 쓰는 법 — '상태' 칸만 바꾸면 됩니다

| 상태 | 언제 | 자동으로 되는 것 |
|---|---|---|
| 신규 | 새로 들어옴(자동) | — |
| 연락함 | 전화·카톡 연락 후 | — |
| 상담 완료 | 상담을 마쳤고 계약은 아직 | 상담 완료일·**파기 예정일(+6개월)** 기록 |
| 보류 | 연락이 안 되거나 보류 | 상담 완료일·파기 예정일 기록 |
| 계약 | 계약 고객이 됨 | 파기 예정일 비움(계약 관리로 이관) |
| 파기 | 고객이 삭제를 요청함 | — (줄을 직접 삭제하세요) |

- **파기 예정일이 지난 줄은 매일 새벽 4시에 자동 삭제**됩니다(setup이 예약해 둠). 동의 문구의 "상담 완료 후 6개월 이내 파기"를 지키는 장치입니다.
- '담당 메모' 칸은 자유롭게 쓰세요.
- 같은 번호로 2분 안에 다시 누르면 한 번만 저장됩니다(중복 클릭 방지).
- `=`, `+`, `-`, `@`로 시작하는 입력은 수식으로 실행되지 않도록 앞에 `'`가 붙어 저장됩니다.
- 숨은 칸을 채우는 스팸 봇은 저장하지 않고 조용히 무시합니다.

## 코드를 고쳤을 때 (주소 유지)

`Code.gs`를 수정·저장한 뒤 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**.
이렇게 하면 웹 앱 URL이 바뀌지 않아 `config.js`를 다시 고칠 필요가 없습니다.
('새 배포'를 누르면 URL이 새로 생깁니다 — 그때는 config.js도 바꿔야 합니다.)

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "주소가 아직 연결되지 않았습니다" | config.js에 URL이 들어갔는지, `/exec`로 끝나는지(`/dev` 아님) |
| "전송하지 못했습니다" | 배포 액세스가 '모든 사용자'인지 · 4-5의 URL 테스트가 되는지 |
| 시트에 줄은 생기는데 메일이 안 옴 | `NOTIFY_EMAILS` 주소, 스팸함. 일반 Gmail 계정은 하루 메일 발송 한도(약 100명)가 있습니다 |
| 실행 기록 보기 | Apps Script 왼쪽 **실행** 메뉴 → 오류 내용 확인 |
| 자동 파기가 안 됨 | Apps Script 왼쪽 **트리거**에 `purgeExpired`(매일)가 있는지. 없으면 setup을 다시 실행 |

## 개인정보 관련 (꼭 함께 정리)

- 접수 내용이 **구글 클라우드(해외 서버 포함)**에 저장되므로, 홈페이지 **개인정보처리방침**에 수집 항목·보관 장소(Google 스프레드시트)·보유 기간·파기 방법·문의처를 적어 두는 것이 좋습니다. 동의 문구에는 "보관: 구글 스프레드시트(아크즈마케팅 계정)"를 이미 넣어 두었습니다.
- 시트는 **아크즈 계정만** 접근하도록 두고, 링크 공유('링크가 있는 모든 사용자')를 켜지 마세요. 함께 보는 사람이 생기면 그 사람 계정만 개별 초대하세요.
- 위 내용은 운영 체크리스트이며 법률 자문이 아닙니다. 정확한 고지 범위는 개인정보보호위원회 안내나 전문가 확인을 권합니다.
